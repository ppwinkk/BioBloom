อุณหภูมิเพียงอย่างเดียวไม่สามารถยืนยันว่าปุ๋ยหมักพร้อมใช้หรือคำนวณเปอร์เซ็นต์การย่อยสลายจริงได้

ประวัติข้อมูลของถังหมัก

แสดง 50 รายการล่าสุดของถังที่เลือกจากหน้า Dashboard

เวลาอุณหภูมิความชื้นอากาศความชื้นวัสดุหมัก RAWพัดลม (ที่บันทึก)ปั๊ม (ที่บันทึก)

🔗 เชื่อมต่อ ESP8266 ผ่าน Supabase

เว็บจะอ่านข้อมูลจากตาราง bins และ sensor_readings โดยใช้ bin_id ที่สัมพันธ์กับถังจริง ESP8266 ต้องส่งข้อมูลเข้าฐานข้อมูลด้วยโปรแกรมแยกต่างหาก

ข้อควรระวังด้านความปลอดภัย

ใช้เฉพาะ publishable/anon key บนหน้าเว็บ ห้ามใส่ service_role หรือรหัสลับของอุปกรณ์ เปิด Row Level Security (RLS) และกำหนดนโยบาย SELECT ให้เหมาะสมก่อนใช้จริง

เวอร์ชันนี้เหมาะสำหรับทดลองในเครื่อง ไม่ควรเผยแพร่หน้าเว็บพร้อมข้อมูลหรือสิทธิ์อ่านฐานข้อมูลที่เป็นส่วนตัวโดยไม่มีระบบล็อกอิน

รูปแบบตารางที่เว็บคาดหวัง:
bins: id, device_code, name
sensor_readings: bin_id, temperature, humidity, compost_moisture_raw, fan_status, pump_status, recorded_at

โหมดบอร์ดจริงอ่าน UUID จากตาราง bins โดยตรง ส่วนโหมดจำลองเก็บข้อมูลแยกในเบราว์เซอร์
