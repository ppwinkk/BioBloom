ใช้ระบบ Supabase จากโค้ดเดิม รับค่าจาก ESP8266 / ESP32 ทั้ง 3 ถังผ่านฐานข้อมูล ตัว Dashboard เป็นแบบอ่านอย่างเดียว ไม่มีคำสั่งควบคุมปั๊มหรือพัดลม

02 / รหัสอุปกรณ์ 3 ถัง

ต้องตรงกับ device_code ในตาราง bins

01 / น้ำธรรมดา
02 / หมัก 1 วัน
03 / หมักสุกแล้ว

03 / วิธีรับค่าจากบอร์ด

ESP8266/ESP32 → Supabase → Dashboard

  1. ติดตั้งเซนเซอร์ pH ที่สอบเทียบแล้ว พร้อมเซนเซอร์อุณหภูมิและความชื้น
  2. ให้ฐานข้อมูลมีตาราง bins และ sensor_readings
  3. บันทึกอุปกรณ์ 3 รหัสใน bins.device_code ให้ตรงช่องทางซ้าย
  4. ให้โปรแกรมบอร์ดส่งค่าเซนเซอร์เข้าตาราง readings พร้อม bin_id ที่สัมพันธ์กับแต่ละถัง
  5. ตั้งค่า Row Level Security (RLS) สำหรับการอ่านข้อมูล แล้วเลือกโหมด “บอร์ดจริง”
bins: id, device_code, name sensor_readings: bin_id, temperature, humidity, ph, compost_moisture_raw, fan_status, pump_status, recorded_at
ข้อควรระวัง: ต้องเพิ่มคอลัมน์ ph ถ้าตารางเดิมไม่มี และควรให้บอร์ดส่งข้อมูลผ่าน API Gateway / Edge Function ที่ตรวจสอบตัวตน ห้ามเปิด INSERT สาธารณะหรือใส่ secret key ในเว็บ

หน้าเว็บจะอ่านเฉพาะข้อมูลที่มีอยู่จริง ไม่สร้างข้อมูลปลอมหากบอร์ดยังไม่ส่งค่ามา

02 / DAY ONE
5.2
